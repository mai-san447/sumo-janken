# 相撲じゃんけん

じゃんけんアプリ（`janken`）を相撲ふうにアレンジした作品です。
手をえらんで勝つと、相手の力士を土俵のはしへ 1 歩ずつ押します。

## あそびかた

1. グー・チョキ・パーのボタンをえらぶ。
2. じゃんけんに勝つと、相手を 1 歩おす。
3. 2 歩おし出したら勝ち。おし出されると負け。
4. あいこは「のこった」で仕切り直し。

## 工夫したところ

- じゃんけんに「土俵バトル」のルールを足した。勝つたびに力士が動く。
- 相撲会場のピクセルアートを背景にして、その上で力士が動くようにした。
- 手をえらぶとすぐ結果を出さず、1 秒くらい手をパラパラ切りかえる演出を入れた。
- 取組開始・勝ち・負けで効果音を鳴らし分けた。
- 連勝の回数を数えて、2 連勝からは強く表示する。
- 勝つと相手が倒れて座布団が舞う。

## ファイルについて

ゲームには効果音と画像を使います。なくてもゲームは動きます
（その音が鳴らない・絵が出ないだけ）。

- 効果音 … `sounds` フォルダーに入れる
- 画像 … `images` フォルダーに入れる

## 難しかったところ

じゃんけん 1 回ごとの押し合いと、勝負の決着・仕切り直しのタイミングを
うまくつなぐところが難しかったです。
次は決まり手や力士の動きをもっとふやしたいです。
