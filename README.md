# ①課題名
すもうじゃんけん

## ②課題内容（どんな作品か）
- じゃんけんアプリを相撲ふうにアレンジした作品です。
- 勝つと相手の力士を土俵のはしへ 1 歩おし、2 歩おし出せば勝ちです。

## ③アプリのデプロイURL
https://emko.work/sumo-janken/

## ④アプリのログイン用IDまたはPassword（ある場合）
- なし（ログインはありません）

## ⑤工夫した点・こだわった点
- じゃんけんに「土俵バトル」のルールを足し、勝つたびに力士が左右に動くようにしました。
- 相撲会場のピクセルアートを背景にして、その上で力士が動くようにしました。
- 取組開始・勝ち・負けで効果音を鳴らし分け、連勝の回数も数えて表示しました。

## ⑥難しかった点・次回トライしたいこと（又は機能）
- じゃんけん 1 回ごとの押し合いと、勝負の決着・仕切り直しのタイミングをつなぐのが難しかったです。
- 次は決まり手のバリエーションをふやしたいです。
- 力士の動きのアニメーションをもっとふやしたいです。
